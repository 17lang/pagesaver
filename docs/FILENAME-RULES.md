# 自动规范文件名

修订 1，2026-11-06，适用 Pagesaver 0.7.0。

## 产品与交互

“设置 → 文件命名”提供默认开启的“自动规范文件名”。开启时显示“时间在前”和“时间在后”，默认前者。说明文字列出净化范围、发布日期优先及长标题完整保留。关闭后隐藏日期位置选项，并使用 0.6.0 原命名方式。原有设置自动补上默认命名选项，三格式已有保存目录保留。

同一项配置作用于 PDF、HTML 和 Markdown，包括整页 PDF、选区 PDF、浏览器下载、本机目录和 Markdown 交给 Obsidian 的文件名。配置在点击“保存设置”后生效。仅修改命名选项不会要求重新连接保存工具检查未变的目录。

对应实现与字符规则见[净化规则](#净化规则)。

## 净化规则

按 Owner 提供的 Filename Governor v0.4.4 规则适配。启用与日期选项见[产品与交互](#产品与交互)。

- Unicode NFC 归一化，按码点遍历。
- 保留 Unicode 字母、组合标记、数字与英文句点，保持大小写。
- 空格、标点、表情、控制字符等连续替换成一个短横线，首尾分隔符省略。
- 保存格式确定扩展名，使用小写 `.pdf`、`.html` 或 `.md`。标题自带的英文句点保留，如 draw.io、Qwen3.8、正文中的 .md。
- 纯符号或纯句点标题使用“未命名”，保留实际保存格式的扩展名。
- 主体不截断。超过操作系统的文件名或路径限制时，仍以实际写入结果为准，不承诺任意长度都能落盘。
- 重名沿用现有浏览器/本机工具的自动编号和不覆盖行为，编号样式由写入方决定。Obsidian 交接保留无 overwrite 标志，实际应用建笔记结果仍需在 Obsidian 确认。

## 日期

优先读取页面文章发布日期，包括 article:published_time、datePublished、pubdate 等语义元数据，JSON-LD 的 datePublished，以及公众号 publish_time/ct。忽略正文中无语义的任意日期。Markdown 也可使用 Defuddle 提取的发布日期。

日期按第一处 `YYYY/M/D` 或 `YYYY-M-D` 匹配，校验月 1–12、日 1–31，再补零为 YYYY-MM-DD。日期字符串含时区时保留其中的日历日期，避免 UTC 换算造成前一天或后一天。公众号 Unix 时间按中国时区取日期。

取不到有效日期时使用保存当天的本地日期。Owner 交接文档第 4 节采用此回退，但后文和参考实现说不加日期。0.7.0 明确采用第 4 节，保证默认日期命名一致。

标题开头或末尾已带 YYYY-MM-DD 时保留该日期与位置，不再重复添加。否则根据选项生成：

```text
2026-03-05-draw.io-中文-76.md
draw.io-中文-76-2026-03-05.md
```

## 实现与验证

规则模块 [filename-rules.js](../options/filename-rules.js) 复用交接算法，提供标题、文件及复合扩展名净化。页面日期在 [page-metadata.js](../content/page-metadata.js) 提取，统一在 background.js 的 saveFile 中使用，向三条写入路线传递同一个最终名称。

设置在原 storage key 下新增 naming.enabled / naming.datePosition。产品与体验由本文件承载，技术总体说明见 [三条保存路线](ARCHITECTURE.md#三条保存路线)。

规则自测见 tools/test-filename-rules.cjs，覆盖交接文档 16 例、日期位置、无截断、缺省迁移和日期提取。真实浏览器检查见 tools/test-zen-naming.py，覆盖开关持久化、关闭恢复旧方式、两种日期位置、三格式真实生成和重名保护。验证记录见 [本轮验证](VERIFICATION.md#070-自动规范文件名)。
