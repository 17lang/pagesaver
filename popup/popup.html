选取局部 · 自动避开悬浮浮层

① 鼠标移到内容上，红框自动套住整块内容；滚轮 / Q W 可换成更小或更大的层，单击确认。
② 按住鼠标拖动出一个矩形，Enter 或点「截取此区域」确认。
确认后只截取选中范围，自动生成单页 PDF 并下载。

网页存档 · 单个 HTML 文件

把整页连同图片、字体、样式全部内嵌进一个 .html，断网双击也能原样打开。
保存时页面会显示和生成 PDF 一致的进度条，完成后自动下载。

阅读存档 · 单个 Markdown 文件

只保留文章正文，转成 .md 文件（去掉导航、广告、页脚）。断网也能在任意 Markdown 编辑器里看。
可在设置中选择保存位置。
